# 🍦 متجر آيس رويال (ICE ROYAL) - منصة بيع الآيسكريم مع لوحة التحكم الكاملة

مشروع متجر إلكتروني متكامل للواجهات الأمامية (Frontend E-Commerce) متخصص في بيع الآيسكريم الحرفي والجيلاتو وبوكسات الجمعات، مدمج معه **لوحة تحكم إدارية احترافية (Admin Dashboard)** بشريط جانبي (Sidebar) وتجربة مستخدم (UI/UX) استثنائية، مبني باستخدام **React** و **Tailwind CSS**.

---

## 🎨 لوحة الألوان المعتمدة (Color Palette)
تم اعتماد التدرجات اللونية المحددة بدقة لتمنح هوية بصرية فاخرة ولذيذة بطابع التوت والكرز:
- `#4F1A16`: العنابي الداكن الفاخر (Dark Berry) - للنصوص الأساسية، خلفيات الشريط الجانبي (Sidebar)، والأزرار الرئيسية.
- `#782722`: الأحمر الكرزي المعتق (Maroon Wine) - للحدود والأيقونات وخلفيات العناصر المحددة.
- `#9C322B`: القرمزي الملكي (Royal Crimson) - لون الهوية الأساسي وشريط التنقل والتفاعل.
- `#C94238`: الأحمر التوتي الحيوي (Vibrant Berry) - لأزرار الإجراء والبطاقات والتمرير.
- `#F24F44`: الأحمر الفراولي المشرق (Bright Strawberry Coral) - للشارات، العروض، وأكواد الخصم.

## 🧭 التبديل السلس بين واجهة المتجر ولوحة التحكم
- يمكن لأي مستخدم أو مسؤول النقر على زر **«لوحة التحكم»** الموجود في الهيدر العلوي للدخول فوراً إلى بيئة الإدارة.
- داخل لوحة التحكم، يتوفر زر سريع **«معاينة متجر الزبائن»** للعودة إلى واجهة المتجر في أي لحظة.

---

## 📊 لوحة التحكم الإدارية (Admin Dashboard)
تتضمن شريطاً جانبياً (Sidebar) ثابتاً للشاشات الكبيرة ومنزلقاً للهواتف الذكية مع الأقسام التالية:

1. **نظرة عامة والإحصائيات (Overview & Analytics)**:
   - بطاقات مؤشرات الأداء الرئيسية (KPIs): إجمالي المبيعات، عدد الطلبات، النكهات النشطة، ومتوسط قيمة سلة الشراء مع نسب النمو.
   - رسم بياني تفاعلي لمبيعات الأيام السبعة بالأسبوع.
   - بطاقة مراقبة الجودة والبرودة (درجة حرارة التجميد -19°C، مخزون الثلج الجاف، متوسط زمن التوصيل).
   - جدول سريع لآخر الطلبات المستلمة مع إمكانية تحديث الحالة فوراً.
   - قائمة النكهات الأكثر مبيعاً ونسبة الإقبال.

2. **إدارة النكهات والمنتجات (Products Management)**:
   - جدول كامل للمنتجات مع إمكانية البحث والفلترة حسب التصنيف.
   - نافذة منبثقة (Modal) لإضافة نكهة آيسكريم جديدة أو تعديل صنف حالي (الاسم، التصنيف، السعر، السعرات، الوزن، الصورة، والشارة).
   - حذف وتعديل الأصناف مع انعكاس فوري على واجهة المتجر.

3. **إدارة وتتبع الطلبات (Orders Management)**:
   - تصنيف الطلبات حسب الحالة (الكل، قيد التجهيز، جاري التوصيل، المكتملة).
   - قائمة منسدلة فورية لتغيير حالة أي طلب (قيد التجهيز في المطبخ، في الطريق مع السائق، تم التوصيل، ملغي).
   - نافذة استعراض الفاتورة التفصيلية مع بيانات العميل وملاحظات التوصيل.

4. **كوبونات وأكواد الخصم (Discounts & Coupons)**:
   - استعراض الأكواد الحالية (`BERRY20`, `SWEET10`, `SUMMER15`).
   - نسبة الخصم، مرات الاستخدام، والحد الأدنى للطلب.
   - تفعيل أو تعطيل الكوبون بنقرة واحدة، أو إنشاء كود خصم جديد.

5. **إعدادات المتجر (Store Settings)**:
   - تعديل اسم المتجر، الهاتف، البريد الإلكتروني.
   - ضبط رسوم التوصيل المبرد وحد الشحن المجاني وساعات العمل اليومية.
   - تغيير حالة استقبال الطلبات (مفتوح / مغلق مؤقتاً).

---

## 🍨 واجهات متجر الزبائن (Storefront)
1. **الصفحة الرئيسية (Home Page)**: هيرو سكشن، استعراض النكهة الملكية، التصنيفات، الأكثر طلباً، عروض بوكسات الجمعات، وآراء العملاء.
2. **صفحة المنتجات (Products Catalog)**: فلترة حسب التصنيف، شريط بحث، ترتيب المنتجات، وبطاقات التخصيص.
3. **صفحة تفاصيل المنتج (Product Details)**: أحجام التقديم، الإضافات والتوبينغ، القيم الغذائية، واحتساب السعر المباشر.
4. **صفحة الطلبات (My Orders)**: سجل الطلبات مع نافذة تتبع حية وزر إعادة الطلب.
5. **سلة المشتريات التفاعلية (Cart Drawer)**: عداد الشحن المجاني، تطبيق أكواد الخصم، وإتمام الطلب.
